# Skill Seekers — Ingesta & Búsqueda Activa de Skills

Descubre, evalúa e ingiere automáticamente nuevas habilidades de agentes AI desde repositorios públicos antes de ejecutar tareas complejas.

## Workflow

1. **Escanear Requerimientos**: Identificar lagunas de conocimiento o librerías no cubiertas.
2. **Buscar en Fuentes**: Consultar SkillRepo, GitHub y repositorios comunitarios.
3. **Validar e Ingerir**: Descargar y verificar `SKILL.md` bajo especificaciones de agentskills.io.
