# SkillClaw — Self-Improving Skill Infrastructure

Based on [AMAP-ML/SkillClaw](https://github.com/AMAP-ML/SkillClaw) (2.5k+ ★), **SkillClaw** is a background optimization infrastructure for power users that refines and sharpens agent skills based on real usage data.

## Features

- **Transcript Analysis**: Scans session logs to detect where skills were ambiguous or ineffective.
- **Automatic Refinement**: Edits prompt rules and triggers to eliminate edge cases without manual gardening.
- **Skill Pruning**: Highlights unused or redundant skills to keep prompt contexts lean.
