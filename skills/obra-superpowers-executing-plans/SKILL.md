# Superpowers — Executing Implementation Plans

Execute approved implementation plans step-by-step with continuous verification and progress logging.

## Execution Checklist

1. **Follow Step Order**: Work strictly through planned tasks.
2. **Verify Each Step**: Run automated tests after every code change.
3. **Log Progress**: Mark completed steps in `implementation_plan.md` or `walkthrough.md`.
