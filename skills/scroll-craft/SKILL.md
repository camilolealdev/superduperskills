# Scroll Craft — Modern Scroll-Driven Animations & Interactions

Based on [nateherkai/scroll-craft](https://github.com/nateherkai/scroll-craft), this skill provides techniques for creating fluid 60fps scroll animations using modern web standards (CSS Scroll-Driven Animations API, View Timelines, Scroll Timelines) without heavy JS dependencies.

## Key Scroll Patterns

1. **CSS Scroll-Driven Timelines**: Uses native `scroll()` and `view()` CSS functions for zero-main-thread scroll animations.
2. **Sticky Section Pinning**: Pin content sections cleanly while internal elements animate.
3. **Parallax Depth Effects**: Multi-layered depth scrolling using CSS transforms and container queries.
4. **Progress Indicators**: Smooth top/bottom scroll progress meters tied to viewport scroll depth.
