# Computer Use — Background Desktop & GUI Automation

Based on [NousResearch/computer-use](https://skillrepo.dev/skills/NousResearch/computer-use) (v1.0B), this skill automates desktop GUI interactions without interrupting the user's workflow.

## Operational Capabilities

- **Synthetic Input**: Dispatches background mouse clicks and keystrokes.
- **Screen Perception**: Captures display bounds and crops target UI elements.
- **Coordination Mapping**: Translates element bounding boxes to OS input coordinates.
