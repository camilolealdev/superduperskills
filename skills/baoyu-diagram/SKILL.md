# Baoyu Diagram — Dark-Themed Vector SVG Diagram Generator

Based on [jimliu/baoyu-diagram](https://skillrepo.dev/skills/jimliu/baoyu-diagram) (v1.0B), this skill generates scalable dark-mode SVG diagrams.

## Design Aesthetic

- **Dark Background**: `#0D1117` background with `#E6EDF3` text contrast.
- **Node Geometry**: Rounded rectangles (`rx=8`) with glowing 1.5px accent borders (`#58A6FF`, `#7EE787`).
- **Typography**: Clean monospace / sans-serif stack with clear hierarchy.
