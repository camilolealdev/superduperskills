# Superpowers — Brainstorming & Requirements Crystallization

Before diving into writing code, pause and ensure user intent and scope are crystal clear.

## Workflow

1. **Ask Clarifying Questions**: Ask 2-4 targeted questions focused on edge cases, user workflows, and constraints.
2. **Break down Spec in Small Chunks**: Present specifications in digestible markdown sections (2-3 paragraphs max per chunk).
3. **Obtain Explicit Approval**: Ensure the user confirms the spec before generating implementation plans.
