# Impeccable — Design & Frontend Guidance Suite

Paul Bakaus's Impeccable design guidance for AI coding agents to eliminate generic SaaS templates and AI design tells.

## 23 Core Commands

1. `/impeccable init`: Gather durable product context and write `PRODUCT.md`.
2. `/impeccable polish`: Final pass, design system alignment, and shipping readiness.
3. `/impeccable audit`: Run technical quality checks (a11y, performance, responsive layout).
4. `/impeccable critique`: UX design review: visual hierarchy, clarity, emotional resonance.
5. `/impeccable bolder`: Amplify boring designs with contrast and scale.
6. `/impeccable quieter`: Tone down overly busy or loud designs.
7. `/impeccable distill`: Strip UI down to its bare essence.
8. `/impeccable harden`: Add error handling, text overflow, i18n, and edge cases.
9. `/impeccable shape`: Plan UX/UI architecture before writing code.
10. `/impeccable craft`: Full shape-then-build flow with visual iteration.
11. `/impeccable document`: Generate root `DESIGN.md` from project code.
12. `/impeccable extract`: Extract reusable design tokens into design system.
13. `/impeccable onboard`: First-run flows, empty states, activation paths.
14. `/impeccable animate`: Add purposeful, non-distracting motion.
15. `/impeccable colorize`: Introduce strategic, harmonic color palettes.
16. `/impeccable typeset`: Fix typography hierarchy, letter-spacing, and line-heights.
17. `/impeccable layout`: Fix layout grid, spacing rhythm, and alignment.
18. `/impeccable delight`: Add moments of visual joy and micro-interactions.
19. `/impeccable overdrive`: Add technically extraordinary effects.
20. `/impeccable clarify`: Improve unclear UX copy and label readability.
21. `/impeccable adapt`: Adapt interfaces for mobile, tablet, and desktop form factors.
22. `/impeccable optimize`: Core Web Vitals and rendering performance fixes.
23. `/impeccable live`: Visual variant iteration mode in the browser.

## Anti-Pattern Rules

- **No Pure Grays**: Always tint grays with primary brand hue.
- **No Card Inception**: Avoid nesting cards inside cards.
- **No Generic Fonts**: Avoid unstyled system fallback fonts.
