# Superpowers — Subagent-Driven Development

Decompose large features into decoupled sub-tasks dispatched to dedicated subagents.

## Principles

1. **Isolated Contexts**: Give each subagent a single focused goal and standard file bounds.
2. **Verification Gate**: Audit subagent deliverables using automated tests before merging back into main context.
