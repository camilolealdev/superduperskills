# Matt Pocock Skills — Pragmatic Composable Engineering

Based on [mattpocock/skills](https://github.com/mattpocock/skills) (235k+ ★), this collection provides small, composable, and editable skills designed for real engineering rather than fragile "vibe coding."

## Philosophy

> "Giant process frameworks take away your control. Keep skills small, modular, and editable so you can customize them to your exact codebase."

---

## Core Included Workflows

1. **`ask-matt`**: Intelligent router over composable engineering skills to pick the exact workflow for your situation.
2. **`implement`**: Task-based implementation based on specifications or issue tickets.
3. **`diagnosing-bugs`**: Systematic diagnosis loop for hard bugs and performance regressions.
4. **`domain-modeling`**: Domain-driven model design and type-level boundary definition.
5. **`codebase-design`**: Vocabulary and patterns for designing deep, maintainable TypeScript modules.
6. **`to-spec`**: Converts loose requirements into tight, testable specifications.

---

## Usage Patterns

- **One-time Setup**: Run setup once per repository to configure TypeScript linting & type assertion helpers (`@total-typescript/shoehorn`).
- **Composition**: Pair with `ponytail` for minimal diffs and `spec-kit` for spec-driven workflows.
