# Taste Skill — Anti-Slop Frontend Framework

Elevate AI-generated frontend interfaces with refined design taste, intentional typography, custom color palettes, and editorial layout structures.

## Core Rules

1. **Avoid Boilerplate tells**: No generic blue/purple gradient buttons on plain white backgrounds.
2. **Editorial Hierarchy**: Pair high-contrast display typography with refined body copy.
3. **Intentional Spacing**: Use asymmetrical margins and generous padding for breathing room.
4. **Custom Color Harmonies**: Curate HSL palettes instead of raw hex values.
