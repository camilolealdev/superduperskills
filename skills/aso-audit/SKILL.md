# ASO Audit — App Store Optimization & Listing Performance

Based on [coreyhaines31/aso-audit](https://skillrepo.dev/skills/coreyhaines31/aso-audit) (v1.1A), this skill audits App Store metadata.

## Audit Vectors

- **Title & Subtitle**: Keyword density check in the top 30-character fields.
- **Screenshot Messaging**: Ensures value proposition is readable in thumbnail view within 2 seconds.
- **Localization**: Verifies metadata localized for primary target languages.
