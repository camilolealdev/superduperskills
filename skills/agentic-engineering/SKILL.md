# Agentic Engineering — Eval-First Development & Model Routing

Based on [affaan-m/agentic-engineering](https://skillrepo.dev/skills/affaan-m/agentic-engineering) (v1.2B), this skill defines the operating framework for engineers leveraging AI agents at scale.

## Core Framework

1. **Eval-First Execution**: Define automated test assertions before delegating code generation to subagents.
2. **Task Decomposition**: Break complex initiatives into independent, sub-20-minute execution blocks.
3. **Cost-Aware Routing**: Direct high-reasoning tasks to top-tier models and routine formatting to lightweight models.
