# Redesign Skill — UI Modernization & Visual Transformation

Based on [nexu-io/open-design/skills/redesign-skill](https://github.com/nexu-io/open-design/tree/main/skills/redesign-skill), this skill provides a structured workflow for taking legacy or uninspiring user interfaces and completely modernizing them.

## Redesign Workflow

1. **Visual & Usability Audit**: Identifies clunky layouts, dated gradient choices, poor typography hierarchy, and accessibility bottlenecks.
2. **Design Direction Selection**: Chooses an opinionated visual aesthetic (e.g. Glassmorphism, Clean SaaS, Cyber-Brutalism, Modern Minimalist) tailored to the brand domain.
3. **Component Modernization**: Replaces dated HTML forms, tables, and navigation with modern components (Radix primitives, Tailwind CSS v4, subtle micro-interactions).
4. **Responsive & Mobile Refinements**: Ensures flawless fluid layouts across mobile, tablet, and desktop breakpoints.
